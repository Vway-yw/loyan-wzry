# 王者荣耀热点

王者荣耀热点/爆料/攻略查询插件，从微信公众号搜索实时抓取，30 分钟自动刷新保证时效性。

## 安装

在 LoyanBot 插件商店中搜索「王者荣耀热点」即可安装。

## 命令列表

| 命令 | 说明 | 权限 |
|---|---|---|
| `/王者热点` | 🔥 查看王者荣耀最新热点 TOP10 | 所有人 |
| `/王者荣耀热点` | 同上 | 所有人 |
| `/王者资讯` | 同上 | 所有人 |
| `/王者爆料` | ⚡ 版本更新/新皮肤爆料 | 所有人 |
| `/王者更新` | 同上 | 所有人 |
| `/王者攻略` | 📖 通用攻略 | 所有人 |
| `/王者攻略 <英雄名>` | 📖 指定英雄攻略（例：/王者攻略 西施） | 所有人 |

## 特点

- ⏱️ 30 分钟缓存自动刷新，保证时效性
- 🔎 多关键词定向搜索（热点/爆料/攻略）
- 📱 来源：微信公众号实时搜索结果
